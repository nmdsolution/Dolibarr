# À propos

ContratPlus est un plugin permettant de renouveler les services expirés 
d'un contrat. Ce plugin est configurable et possède plusieurs options. Le
plugin peut automatiser, en plus du renouvellement des services expirés 
du contrat, la création d'un brouillon de la facture après renouvellement,
la validation de ce brouillon et l'envois par mail de la facture aux 
clients.
ContratPlus propose un système de liste avec des cases à cocher permettant
de cocher plusieurs contrats et de renouveller tout les contrats cochés.


# Installation

- Glisser et décompresser le dossier /htdocs/custom dans votre installation de Dolibarr
- Activer le module dans Dolibarr via Accueil > Configuration > Modules
